1. EXECUTIVE SUMMARY

Pin'Go CRM is a Symfony 6.4 LTS web application currently structured as a
Twig-rendered CRM interface. The application uses thin Symfony controllers,
reusable Twig components, Symfony Asset Mapper/importmap, vanilla JavaScript,

local WAMP development uses dynamic assets from assets/ instead of stale
compiled output in public/assets/. It also adds Composer helper scripts,

6.5 Development asset safeguards

Files:
- src/AssetMapper/DevCompiledAssetMapperConfigReader.php
- src/EventSubscriber/PreventDevAssetCompileSubscriber.php
- bin/dev-clean-assets.php
- README.md

Purpose:
- Keep APP_ENV=dev tied to dynamic Asset Mapper source files from assets/.
- Prevent accidental asset-map:compile execution in APP_ENV=dev.
- Provide a cleanup path for stale compiled public/assets files.
- Preserve production compilation through APP_ENV=prod.

Behavior:
- DevCompiledAssetMapperConfigReader replaces the compiled Asset Mapper config
  reader in the dev service container only.
- It reports that compiled config does not exist, returns an empty config, and
  refuses to save compiled config in development.
- PreventDevAssetCompileSubscriber listens to console commands and disables
  asset-map:compile when the Symfony kernel environment is dev.
- bin/dev-clean-assets.php moves public/assets to
  var/compiled-assets-backups/assets-YYYYMMDD-HHMMSS when stale compiled files
  need to be removed from development.
- README.md documents the development rule:
  APP_ENV=dev uses dynamic assets from assets/.
- README.md documents the production rule:
  APP_ENV=prod uses compiled assets in public/assets/.

8.4 Development and production asset workflow

Development workflow:
- Do not run asset-map:compile in APP_ENV=dev.
- Symfony Asset Mapper should serve JavaScript and CSS dynamically from assets/.
- If stale public/assets files cause old JavaScript or CSS to be served, run
  the cleanup utility before clearing the dev cache.

Development helper scripts in composer.json:
- composer dev:assets:clean
  Runs php bin/dev-clean-assets.php.
- composer dev:cache:clear
  Runs php bin/console cache:clear --env=dev.

Production helper script in composer.json:
- composer prod:assets:compile
  Runs php bin/console asset-map:compile --env=prod.

Important runtime caveat:
- These Composer scripts call php from PATH.
- On this workstation, PATH currently resolves php to PHP 7.4.33.
- Until PATH is updated to PHP >= 8.1, run Symfony console commands with
  C:\wamp64\bin\php\php8.3.28\php.exe or update PATH before using the scripts.

Ignored generated/log files:
- public/assets/ is ignored as generated Asset Mapper output.
- assets/vendor/ is ignored as generated importmap/vendor output.
- server.log and server.err are ignored for local development logs.
